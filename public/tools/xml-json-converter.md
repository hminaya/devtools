# XML ↔ JSON Converter

> Bidirectional XML-to-JSON and JSON-to-XML converter using the familiar @attr / _text convention; repeated tags collapse into arrays

Live tool: https://www.developers.do/tools/xml-json-converter
Category: Formatting

Free and browser-based: input data is processed locally on the user device and is not uploaded to a server.
