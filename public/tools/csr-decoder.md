# Certificate & CSR Decoder

> Decode X.509 certificates and PKCS#10 CSRs — subject, issuer, expiry, SANs, extensions, and key details

Live tool: https://www.developers.do/tools/csr-decoder
Category: Security

Free and browser-based: input data is processed locally on the user device and is not uploaded to a server.
